# offwork-timer

Windows 下班倒數計時器：系統匣 + 浮動條顯示剩餘時間，下班前放煙火提醒。

## 功能

- **自動計算下班時間**：輸入當天上班刷卡時間，依「工作時數 + 午休」算出下班時間。
  - 工作區間跨過午休時，會自動補回午休長度（預設 08:30 上班 → 18:00 下班）。
  - 在午休時段內打卡，從午休結束開始計算。
- **浮動小條**：預設顯示在工作列上方右側，內容為「上班 08:30 ｜ 下班 18:00 ｜ 剩 03:25」。
  - 可用滑鼠左鍵拖曳，位置會記住。
  - 永遠置頂、半透明。
- **系統匣圖示**：直接在圖示上顯示剩餘時間（HH:MM），滑鼠移上去可看下班時間。
- **顏色提醒**：
  - 藍色：正常倒數
  - 紅色：距離下班 30 分鐘內
  - 綠色：已經可以下班（顯示超時多久）
- **煙火特效**：下班前 10 分鐘，全螢幕播放煙火與彩帶約 9 秒，並顯示「再 10 分鐘下班！」。特效背景透明、滑鼠可穿透，不影響工作；每天只播一次。
- **換日自動重置**：跨日後會自動詢問新的上班時間。
- **開機自動啟動**：可從系統匣選單開關（寫入目前使用者的登錄檔 `HKCU\...\Run`，不需要系統管理員權限）。

## 安裝與執行

需求：Windows、Python 3.8 以上（需含 `py` 啟動器）。

### 方法一：打包成 exe（推薦）

雙擊 `build.bat`，會自動安裝相依套件與 PyInstaller，並輸出：

```
dist\OffworkTimer.exe
```

之後直接執行 `OffworkTimer.exe` 即可，可以把它放到任何資料夾。

### 方法二：直接用 Python 執行

```bat
py -m pip install -r requirements.txt
run.bat
```

## 使用方法

1. 啟動後會跳出視窗詢問「今天上班刷卡時間」，輸入例如 `08:42` 後按確定。
2. 浮動條和系統匣圖示開始倒數。
3. 需要時用選單操作：

| 選單項目 | 浮動條（右鍵） | 系統匣（右鍵） | 說明 |
| --- | :---: | :---: | --- |
| 今天暫停特效 | ✓ | ✓ | 今天不播煙火（隔天自動恢復） |
| 設定上班時間… | ✓ | ✓ | 修改今天的上班時間 |
| 測試特效 | ✓ | ✓ | 立刻播放一次煙火 |
| 隱藏浮動條 / 顯示/隱藏浮動條 | ✓ | ✓ | 系統匣圖示**左鍵**也可以切換 |
| 開機自動啟動 |  | ✓ | 勾選後登入 Windows 時自動啟動 |
| 結束 | ✓ | ✓ | 關閉程式 |

當天設定的上班時間會被記住，重新啟動程式不需要再輸入。

## 設定

第一次執行時，會在程式旁邊（`OffworkTimer.exe` 或 `app.py` 同一個資料夾）自動產生 `config.json`：

```json
{
  "work_hours": 8,
  "lunch_start": "12:00",
  "lunch_end": "13:30",
  "remind_before_min": 10,
  "warn_before_min": 30
}
```

| 欄位 | 說明 |
| --- | --- |
| `work_hours` | 每天工作時數（不含午休），可用小數，例如 `8.5` |
| `lunch_start` / `lunch_end` | 午休起訖時間（HH:MM） |
| `remind_before_min` | 下班前幾分鐘播放煙火 |
| `warn_before_min` | 下班前幾分鐘文字變紅 |

修改後重新啟動程式生效。`config.json` 已列在 `.gitignore`，不會被提交。

當天的上班時間、浮動條位置等狀態存放在 `%APPDATA%\OffworkTimer\state.json`。

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `app.py` | 主程式：浮動條、系統匣、設定與狀態管理 |
| `worktime.py` | 下班時間計算（含午休處理）與時間格式化 |
| `celebrate.py` | 全螢幕煙火與彩帶特效 |
| `build.bat` | 打包成單一 exe |
| `run.bat` | 不打包直接執行 |
| `requirements.txt` | 相依套件（pystray、Pillow） |
